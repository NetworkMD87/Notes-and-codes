# Libron

Unmodified WOFF2 files from the official Libron v0.31 release:
https://github.com/nicoverbruggen/libron/releases/tag/v0.31 (`Libron_Web.zip`).

The upstream licence is in `src/renderer/public/licenses/libron/OFL.txt` and is
copied into the renderer output for distribution by Vite.

Libron can be selected independently for the editor and interface. Selecting it
for the editor also styles Markdown preview code and snippet editing; selecting
it for the interface also styles badges and keyboard hints. Other font selections
retain the existing appearance. Native Windows menus/dialogs use OS typography.
